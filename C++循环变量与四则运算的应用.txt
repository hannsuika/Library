例题：城主在生日的时候，会把自己的生日蛋糕分给城里的小朋友。每年会把蛋糕分成当时年龄的数量，因为城主也喜欢吃蛋糕，所以他每年都会给自己留一块，把剩下的分出去。现在城主刚过完150岁的生日，已经分出去了n块蛋糕。

请你编写程序计算一下城主是是从几岁开始养成这个习惯的。（数据保证 n 一定有解，且最值答案大于1）

代码：

#include <iostream>
using namespace std;
int main()
{
	int n;
	cin >> n;
	for (int i = 1; i <= 150; i++)
	{
		int sum = 0;
		for (int j=i;j<=150;j++ )
		{
			sum += j-1;
		}
		if (sum==n )
		{
			cout<<i;
		}
	}
	return 0;
}
